## Editing

The website reads `src/content/members.json`. Set `rosterYear` and `people` for the featured season, use `seasons` for older recorded seasons, and `alumni` for undated historical records. Photos and LinkedIn, GitHub, and portfolio URLs are optional. Blank photos render initials; blank profile URLs hide their icons. The CMS Members collection edits these same fields.
